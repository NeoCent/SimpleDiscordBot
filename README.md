# Simple Discord Bot

## RU

Простой обучающий бот для Discord, написанный на Node.js с использованием discord.js v14.

Этот бот создан для изучения основ разработки Discord-ботов. Он показывает, как работают команды и кнопки, а также простое переключение языка.

Функции:
- !hello — приветствие пользователя
- !info — информация о боте
- !panel — открывает панель с кнопками
- Кнопки:
  - Hello — отправляет приветствие
  - Info — показывает информацию
  - Language — переключает язык RU / EN

Установка:
npm install discord.js

Запуск:
node index.js

Настройка:
Вставь токен бота в index.js:
client.login("YOUR_BOT_TOKEN");

## EN

Simple Discord bot written in Node.js using discord.js v14.

This bot is made for learning Discord bot development basics. It demonstrates commands, buttons, and simple language switching.

Features:
- !hello — sends greeting
- !info — shows bot information
- !panel — opens button panel
- Buttons:
  - Hello — sends greeting
  - Info — shows info
  - Language — switches language RU / EN

Installation:
npm install discord.js

Run:
node index.js

Setup:
Put your bot token into index.js:
client.login("YOUR_BOT_TOKEN");
