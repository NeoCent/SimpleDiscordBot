КАК СОЗДАТЬ DISCORD-БОТА:

1) Зайди на сайт Discord Developer Portal  
https://discord.com/developers/applications

2) Нажми "New Application"  
Создай приложение (это твой бот)

3) Перейди в раздел "Bot"  
Нажми "Add Bot"

4) Скопируй TOKEN  
Это ключ бота (никому не показывай)

5) Включи обязательно:  
- MESSAGE CONTENT INTENT = ON  
(иначе бот не будет видеть команды)

6) Установи на компьютер Node.js  
https://nodejs.org

7) Создай папку проекта

8) Открой терминал в папке и напиши:
npm install discord.js

9) Создай файл index.js  
И туда вставь код с файла index.js 
Файл находится в этом проекте:>

10) Запуск бота:
node index.js

---

КАК КАСТОМИЗИРОВАТЬ БОТА:

- менять ответы в коде (тексты)
- добавлять команды (!hello, !info)
- добавлять кнопки и меню
- делать несколько языков (ru / en)
- менять имя и аватар в Discord Developer Portal

---

ВАЖНО:

- бот работает только пока открыт терминал
- без токена он не запустится
- без Intent он не видит сообщения
